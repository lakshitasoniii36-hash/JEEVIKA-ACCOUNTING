General Configuration
Master toggle enables or disables manual number entry for all transaction modules at once. You can also turn individual module access ON or OFF below.

Auto 2. Member Receipt
Auto 3. Member Receipt Reversed

Auto 7. Other Receipt (RV)

Auto 9. Contra Entry
Auto 10. Journal Entry JV
Auto 11. Purchase Order
If enabled, the 'Against Bill' field in the Member Receipt screen will be auto-selected based on the receipt's date/month, and the Auto Select button will display ON (read-only). If disabled, it will display OFF and allow the user to write/type the Bill number manually.
